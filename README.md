## 📖 Overview

Hirely is a full-featured recruitment platform that bridges the gap between companies and job seekers. Whether you're a recruiter building a team or a candidate searching for your next opportunity, Hirely delivers a seamless, intuitive experience from job posting to final offer.

---

## ✨ Features

### 👨‍💼 For Recruiters

- Create, edit, and manage job postings
- Track applicants and manage the full application pipeline
- Schedule and manage interviews
- Build and organize interview question banks
- View detailed candidate profiles
- Access a dashboard with hiring analytics and insights

### 👩‍💻 For Job Seekers

- Browse and search available job listings
- Apply to positions with ease
- Upload resumes and supporting documents
- Track application status in real time
- Manage and update your personal profile
- Receive and respond to interview invitations

### 🌟 Platform-Wide

- Secure authentication & role-based authorization
- Fully responsive UI across all screen sizes
- Real-time notifications
- Robust form validation
- Protected routes per user role
- Advanced search & filtering
- Clean, modern UI with smooth animations

## 🛠️ Tech Stack

| UI Framework  | React.js                     |
| Routing       | React Router                 |
| Styling       | Tailwind CSS                 |
| Forms         | React Hook Form              |
| Data Fetching | TanStack Query (React Query) |
| HTTP Client   | Axios                        |
| Animations    | Framer Motion                |
| Icons         | Lucide React                 |
| Build Tool    | Vite                         |

